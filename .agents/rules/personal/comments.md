# Comments

- Follow repo conventions. Don't restate code.
- Implementation: explain constraints, rationale, workarounds, surprising behavior.
- Interfaces: document caller contracts: behavior, inputs/outputs, side effects, errors, usage constraints. Signatures may be insufficient.
- Future reader first. No diff narration or obsolete behavior; change history belongs in commits/PRs.
- Update documentation with behavior.
