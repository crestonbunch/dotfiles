# Preferences

- Follow repo conventions. Stay within scope.
- Work directly by default. Delegate for useful independent research, review, or isolated implementation.
- Available agents only. Specific assignments; review results before use.

## Codex model selection

- **Luna:** Search and summarize text. Do not use for analysis.
- **Terra:** Search code and analyze basic code. Do not use for review.
- **Sol:** Default for most problems. Use it to reason, make choices, plan, write, and review. Use high effort for reviews.
- **Astra:** Use for hard problems, deep reviews, and complex tasks. Use it to plan, write, and review.
