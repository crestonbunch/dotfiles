# Pull requests

- Repo title conventions, template, and merge policy first.
- Find templates in repo root, `.github/`, and `docs/`, including template directories.
- Default title: specific imperative, ≤70 characters, no trailing punctuation.
- Explain motivation/expected behavior, not the diff line by line. Link evidence. Note non-obvious choices, risks, follow-ups.
- Verification: distinguish tests added from checks run. Report unrun checks and known failures accurately.
- Preserve required sections/checklists. Check only completed items; explain non-applicable items.
- Repo policy defines blockers. Separate pre-merge requirements from post-merge follow-ups.
- Omit optional empty boilerplate. Length proportional to change. No attribution/generated-by footer.
