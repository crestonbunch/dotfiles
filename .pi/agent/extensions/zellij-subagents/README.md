# Zellij async subagents

Independently loaded Pi extension (`index.ts`), with no changes to bundled `pi-subagents`.

Inside a Zellij session, press **Alt+Z** or run `/zellij-subagents`. The extension creates a uniquely named tab without focusing it, explicitly focuses the tab by stable ID, then populates stacked read-only Node viewer panes for the **current Pi session's active async children**. Press Alt+Z again from Pi to focus the existing tab. Only Alt+Z or `/zellij-subagents` opens or focuses the tab; closing it manually keeps it closed until the next explicit open. While the tab is active, updates are driven by lifecycle hints plus a 2.5-second authoritative status RPC refresh. Layout changes pause when you switch away, then catch up when you return; background updates never activate the tab. Children absent from a projection remain pending until their identified step in the canonical `status.json` has a terminal status. Only then do they become **Finished · child** panes (neutral: success/failure is not inferred from the snapshot); their viewers continue displaying the actual artifact status and final output. Unreadable, missing or unmatched status retains the pane and cannot authorize clearing or pruning. Run `/zellij-subagents-clear` from Pi to clear only completed panes after a fresh status refresh; active panes remain. If the tab is not active, clearing is queued until you open it again, so clearing cannot switch your view. At most 20 confirmed finished panes are retained per tab; the oldest still-confirmed finished pane is pruned when the cap is exceeded. A waiting placeholder appears only when neither active nor finished panes remain. Zellij's normal tab navigation returns you to Pi.

When a child has a validated `sessionFile`, its pane shows a compact live `fzf` event list fed by `tail` → a bounded read-only Node summarizer. New events appear at the top (up to the latest 10,000 list entries); ↑/↓ or j/k selects entries and the lower preview seeks directly to that event and shows up to 12 KiB of its assistant text, tool call (name and allowlisted/redacted arguments), or tool result/error. Press **/** to search (including j/k characters), **Ctrl+G** to clear search and return to j/k navigation, **Ctrl+J/K** or **Alt+J/K** to scroll the preview, and **Esc** or **Ctrl+C** to exit this pane's viewer only. The list remains after completion and can be scrolled normally without pausing the live feed. User/system prompts, thinking, images and private metadata are not printed. This is a local display, **not** a secret-safe export: visible tool output may still contain sensitive data. The pane waits for a late `sessionFile` and switches to the list automatically; malformed/incomplete or oversized JSONL lines are skipped. Use Pi's `subagent` controls to stop work.

If the child has no usable session file (for example external or nested work), the existing read-only viewer remains as fallback: it tails at most 12 KiB of `output-<step>.log`, shows the `status.json` state, and Ctrl+C exits only that viewer. Closing the dedicated tab manually does not stop children; Alt+Z opens a new tab. On Pi session shutdown/reload, the extension leaves its tab and viewers in place for inspection; the old tab is no longer managed. Reopening after `/reload` creates a new dedicated tab, and `/zellij-subagents-clear` only affects the new tab. Manually close old tabs when done (repeated reloads can leave multiple tabs). While managing a tab, the extension verifies the exact unique tab ID/name and all its pane IDs before modifying it; it leaves externally modified tabs alone. Manual tab closure never stops children.

Requires Pi TUI in Zellij 0.45.1+, `pi-subagents` with event-bus RPC (`data.asyncSnapshot`), Node, and a terminal that forwards Alt+Z to Pi. Transcript mode additionally requires installed `fzf` (tested with 0.74.3) and `tail`. No second Pi session is attached or written. Foreground/in-process subagents are **not** shown. The bounded public snapshot (20 runs, 8 children/node by default) can omit children; in that case reconciliation fails closed rather than deleting panes. If an output artifact is missing or a nested child writes its output outside the parent run directory, the fallback pane says output is unavailable; the extension does not scrape human-readable status text, import package internals, attach a child session, or follow arbitrary output paths. Artifact discovery checks `pi-subagents-*` directories in the OS temp directory for an exact `status.json` run/session identity and ignores other Pi sessions. Status hints alone are never authorization. If a user closes a viewer pane instead of its tab, reconciliation stops rather than mutating an unexpected tab; close the tab and reopen with Alt+Z.

Run safe local tests with `node --test ~/.pi/agent/extensions/zellij-subagents/*.test.mjs` (mock Zellij CLI/process wrapper; no live Zellij session is touched). On Pi `/reload`, old tabs and viewers stay available for review but are no longer managed; explicitly opening again creates a fresh tab.
